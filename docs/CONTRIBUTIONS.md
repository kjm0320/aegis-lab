# 기여도와 설명 가능한 범위

| 역할 | 현재 확인된 기여 |
|---|---|
| 김재민 | 보안 진단 아이디어, 허가된 결과 기반 입력, 무단 스캔 제외, 비공개 배포, 취업 포트폴리오 목표 제시 |
| Codex 지원 | 웹앱 및 실습 코드 작성, 테스트 설계·실행, 사례·문서·PDF 작성, 비공개 배포 지원 |
| 사용자 확인 전 | 코드 독해, 로컬 독립 재현, 직접 수정, 면접 설명 연습, 실제 브라우저 검증 |

이 자료는 AI 도움을 받은 프로젝트입니다. 자동 실행된 실습을 지원자 본인의 수동 모의해킹 실적으로 표현하지 않습니다. 이후 본인이 수행한 작업은 커밋, 실행 로그, 검토 메모와 함께 추가하세요. 실제로 하지 않은 개인 기여나 성과 수치를 문서에 기재하지 않습니다.

## 직접 재현 후 기록할 항목

- 실행 환경과 사용한 명령
- 설명할 수 있는 함수 및 입력부터 출력까지의 흐름
- 직접 수정한 코드와 이유
- 수정 전 실패, 수정 후 통과하는 테스트
- 해결되지 않은 문제와 다음 선택

검토 상태: 사용자 독립 실습 전. 해당 상태는 사용자가 직접 완료 사실을 확인하기 전까지 유지합니다.
