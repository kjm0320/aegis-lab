# 공개 소스와 비공개 사이트

GitHub 소스 공개는 사용자 승인을 받은 범위입니다. 배포 사이트는 비공개로 유지합니다. 이 소스에는 Sites 식별 설정, Git 인증정보, 원본 Git 이력, 개인 연락처를 포함하지 않습니다.

## 공개 범위

- 정적 대시보드와 사례 페이지 코드
- 합성 데이터만 사용하는 프로세스 내부 보안 실습
- 테스트, 실행 기록, 프로젝트 설명 문서와 PDF

실습 코드는 HTTP 서버를 열지 않으며 외부 사이트에 접속하지 않습니다. 운영 대상, 실제 고객 데이터, 비밀키는 포함하지 않습니다.

## CI

`.github/workflows/checks.yml`은 소스 문법, Node 테스트, Python 실습 테스트를 실행합니다. 로컬 실행 증거와 GitHub Actions의 원격 실행 결과를 구분합니다.

첨부 PDF와 실행 증거는 2026-10-20 작성 당시 기록입니다. 최신 코드와 CI 결과는 현재 저장소를 기준으로 확인하세요.
